# コードブック v1.1（2026-10-10、v1 からの差分）

v1 の pilot02 held-out 60件（ChatGPT 監査）の所見を反映した。v1 の定義・規則はそのまま残し、ここに書いた点だけ変える。T01〜T10 の定義は変えない。

## 閾値

- T01〜T12: 0.3、T13: 0.6（全件実行の値、2026-10-10）。T01〜T10 の 0.3 は pilot01 で選び pilot02・pilot03 の held-out で確認（pilot03: 適合率0.81・再現率0.90・F1 0.85）。T11・T12 の 0.3 と T13 の 0.6 は pilot03（v1.1）の確率で F1 が最大の値（T11 0.63、T12 0.86、T13 0.75 だが陽性3件）。
- T11 と T13 は信頼性が低く、閾値は pilot03 の結果を見て決めたため独立に検証されていない。妥当性の確認はすべて別モデル（ChatGPT）による盲検判定との比較（60件×3回）であり、人の参照判定ではない。展開範囲・複合機能・副機能は κ≈0.1 で探索的扱い（集計の主張に使わない）。
- 0.2 未満は非該当、0.2〜閾値は不確実。全確率を保存するので閾値は再実行なしに変えられる。

## テーマの変更

- T11 教育内容・カリキュラム構造・教育方法: 構造・配列・教育期間・教育方法について独立した主張があるときだけ付ける。T01（学修成果との整合）、T02（臨床実習）、T09（EBM）の内容の周りに「カリキュラム」「教育」の語が出るだけでは付けない。評価の場面で教育方法名が出るだけ（TBL の評価など）も付けない。除外は主張単位に働くので、独立した構造の主張があれば T01 等と併記できる。
- T13 教育資源・施設・教育連携: 物的資源（施設・設備・図書・学修スペース・感染対策設備）か、明示された組織的な連携・協力体制に限る。種類を特定しない「資源」「資源配分」、成果の連続性や「一貫した教育」「連携のある教育システム」の表現だけでは付けない。
- T06 と T13: 学修環境のうち支援・相談・安全・配慮が主題なら T06、施設の整備が主題なら T13。両方の主張があれば併記。

## 機能の追加規則

- F5 の「参画」は学生に限る。患者・住民・地域医療者・卒業生の参画は F7（主題がプログラム評価なら F4）。
- 周知・説明だけを求める文は、対象が教員なら F6、学生なら F5、全体なら F7。
- 複合文の段階は主要求の段階を取る。副要求の段階は記録しない。
- 「別対象への要求」と「手段」を区別する。資源配分・連携が支援の手段として出るだけなら副機能にしない。
