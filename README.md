# JACME評価報告書コーパス（試作）

日本医学教育評価機構（JACME）が公開している医学教育分野別評価報告書（82大学、報告書125件、2013〜2025年度）を構造化し、医学教育の変化と取り組みを見るための研究用データと閲覧画面。

- 閲覧画面: https://shoei05.github.io/jacme-corpus/ （`public/site/`）（「図で見る」「資料・審査イベント検索」「テーマ・下位領域×審査の行列」「取り組みカード」「大学別の経時・追加審査」「統計・品質・更新履歴」）
- 公開データ: `public/data/`（集計・判定・承認済みカード）、`data/canonical/`（固定IDつきの表。コメント本文は含まない）
- 分類の定義: `codebook/`
- 処理: `scripts/`（取得・構造化・検証・リリース・公開の各段階）
- 設計と方法: `docs/`

## 含まないもの
報告書の全文・PDF・コメント本文は再配布しない。原文は各表の URL（JACME の元 PDF）で参照する。評価員個人は分析・表示の単位にしない。大学の順位や総合点は作らない。

## 自動分類と確認について
- テーマ・機能・段階のタグは型付き判定モデル（TypeSafe Jev, jev-1.13.0）による自動付与。別モデル（ChatGPT）による盲検判定との比較（60件×3回）で閾値を決めた。人の参照判定による検証は未了。
- 後年再評価・版混在のフラグは Jev を正本、Cloudflare Clef を第2判定者として記録。
- 取り組みカード（IR・内部質保証、6大学12枚）は、出典の該当箇所と照合した別モデルの判定（2回）を経て公開。人による全件確認は未了。
