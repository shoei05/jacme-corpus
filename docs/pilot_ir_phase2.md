## 定義上の未決点

1. 「体制が整備されている」「仕組みが構築され実践されている」の段階: 前者 D1、後者 D2 とした。「構築され実践」は運用の明示と読むが、何が実践されたかは書かれない。境界の文例を増やす必要がある。
2. result_use=全体 の認定: 慶應 101 の 9.0B（アクションプラン立案）と千葉 5（会議での改善）を全体としたが、いずれも立案・改善の内容は不明。「全体」は「プログラム全体を対象とした利用の記載」であって効果の確認ではない、と定義に明記するか。
3. 要求への応答（link_type）の根拠: 報告書は前回要求との対応を書かないので、ほぼすべて研究者の仮説になる。追加審査報告書だけは同じ欄に要求と記載が並ぶので「同対象の明示」とした。仮説の link を公開カードで使うときの表記を決める必要がある。
4. 主体が明示されない決定（旭川の入試枠変更、慶應の入試検討委員会への報告）: from_actor を 不明 型の仮の主体にしたが、不明の主体を actors に置くか、relation 側を空にするか。
5. 後年再評価（千葉 5）の時点: 文単位で分けないと決めたが、2巡目（_02_01）との比較では「2014年時点」と「2017年5月時点」の区別が結論に影響しうる。比較のときは observation の note の観察期間を必ず併記する運用でよいか。
6. 旧審査再掲 と 要求の継続 の違い: 再掲は追加審査報告書の構造上のもの（本審査欄）、継続は追加審査コメント欄や次の巡に同趣旨の要求が出ること、と分けた。同文で継続する例（聖マリアンナ 7.3B）は 要求の継続・basis=同文 とした。

## 未決点への決定（2026-10-10、team-lead 経由の本人判断。practices_v0.1.yaml に反映）

1. D1 と D2: 組織・仕組み・規程が存在する／設置されたとだけ述べる文（「体制が整備されている」「設置した」）は D1。D2 は対象を伴う活動が明示されている文（「〜を収集している」「〜を実施している」「運用している」）。「構築され実践されている」は D2。
2. result_use=全体 は「利用の対象範囲がプログラム全体に及ぶと記載されている」ことを意味し、効果の確認ではない。カードにも同じ注記を置く。
3. 要求への応答（basis=研究者の仮説）はカードでは事実の要約と分け、「研究者による対応づけ。報告書は対応関係を明示していない」と明示した別区画にだけ載せる。
4. 主体が明示されない行為: 大学ごとの仮の主体「主体の記載なし」（actor_type=unspecified）を置き、関係は explicit=false で残す。表示は「主体は明示されていない」。
5. 後年再評価の報告書を含む比較では、観察期間（例: 2014年度＋2017年5月までの改善）を必ず併記する。
6. 旧審査再掲は追加審査報告書内の本審査欄の再掲（同文、構造上のもの）。要求の継続は後の審査の所見として同対象の要求が再び出ること。別のものとして扱う。
