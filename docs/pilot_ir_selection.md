# IR・内部質保証パイロット: 対象大学の選定（Phase 1、2026-10-10）

テーマ: IR・内部質保証（分析結果を意思決定につなぐ仕組み）。対象は6大学14報告書。選定は全件タグ（codebook v1.1、Jev）の T04 密度、F4、observed D3/D4（点検・結果利用の記載）、2巡目の要求（特に requested D4）、領域7系・2.7・9.0 の基本的水準の部分的適合数と、追加審査の有無で行い、対照的な型がそろうように選んだ。タグは自動付与で誤りを含むため、選定の根拠であって結論ではない。

福井大学（88、2023、1巡目のみ）は team-lead の候補だったが、2巡目も追加審査もなく対応比較ができないため今回は外した。単一報告書の参照例として後で加える余地はある（T04 21件、observed D3/D4=6）。

## 対照の型

1. 要求が減った（慶應）／増えた（千葉）。
2. 体制整備の後に局所的な結果利用が記載される（旭川）と、全体的な課題が併存する（京都府立、聖マリアンナ）。
3. 不適合→部分的適合→2巡目の連鎖（大阪公立）。
4. 後年再評価（千葉 2014→2017年5月までの改善を含む）と基準版の違いをまたぐ比較。

## 根拠位置（evidence_spans）

`scripts/22_evidence_spans.py` で14報告書のコメント・総評・概評に PDF 物理ページ（1始まり）、印刷ページ番号、節（領域・下位領域・水準）、`text/<doc>.txt` の文字位置を付け、`canonical/private/evidence_spans.csv` に置いた。文字位置と節は非公開層。公開に出すのは物理ページまで（引用はしない）。照合は NFKC 正規化と空白・私用領域文字の除去で行い、同じ文が複数箇所にあるときは該当する下位領域見出しの後ろで最初の位置を採り、`match_status` に ambiguous と記録した。無作為抽出で pdftotext のページ別出力と突き合わせて確認した。
