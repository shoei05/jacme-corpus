# 自己点検評価報告書：公開データの読み方

2026年10月17日公開。Jevによる分類後に保存した版に基づく、機械抽出・自動分類の暫定データです。

## 対象と公開範囲

JACMEの「大学公開情報」リンク82大学を調べ、75大学の96 PDF・28,508頁を取得しました。岩手医科大学の3分冊をまとめ、94文書として扱います。未入手・未確定は7大学です。報告書本文・引用・PDF・評価員氏名・ローカル作業パスは公開しません。元資料のURLとPDF上のページへリンクします。

## データ

- documents：94文書の所在・文書年・基準版・受審回対応。文書年と受審年度は必ずしも同じではありません。
- comparison_a：16,871行。自己記述の暫定分類と外部評価を併記。alignment（過大・過小）列は公開せず、判定単位の異なる情報の比較から結論を確定しません。
- comparison_b：6,342行。助言事項が自己記述で認識されているかの暫定分類。
- comparison_c：3,324行。改善計画・助言と後の文書の対応。実施や効果の事実認定とは異なります。
- comparison_d：17,053行。テーマ・機能・段階の暫定分類。軸ごとに保留があります。
- area9：comparison_aから基準番号B9/Q9を選んだ1,309行。

`provisional_jev` は条件を満たす暫定分類、`unresolved` は保留です。取り組み分類の `partial_provisional_jev` は軸ごとの一部のみ利用可能です。保留行の分類値はunknownです。source_urlは自己点検報告書の所在、evidence_pageは同PDF上のページです。external_judgmentはconcept_idの下位領域に対する外部判定で、個々の基準番号に対する判定ではありません。判定未対応は不適合の意味ではありません。大学の総合点・順位は作成しません。

## 方法と検証状況

基準番号・節・原文ページを機械抽出し、Jev（jev-1.13.0）で分類しました。原文の位置・引用の実在や入力ハッシュをコードで検査していますが、節境界や意味の正しさを全件確認したものではありません。確信度が高くても、分類が正しいとは限りません。過去のJevの実行記録には実行当時の質問文ハッシュを保存していない結果があり、現行入力・回答形式などを照合して再利用しています。

公開表の元となる固定版は17,305基準項目・106,783節・109,226セルです。このうち55,456セルを暫定利用、53,770セルを保留しました。比較ごとの採用条件があるため、利用可能行数はセル数と一致しません。

別途の修復検査では基準見出しの欠落5件を復元する一方、境界確認を厳格化し、未解決扱いは53,956セルになりました。この変更や小規模なGemini試行で得られた修正提案は、今回の公開表には反映していません。全文書の収集、分類値の入力、分類内容と原文との照合が、それぞれ完了したかを区別します。
